## Исправление ошибок в работе с криптографией и улучшение анализа документов

### Проблема:
- Ошибка "Identifier 'analyzeDocument' has already been declared" в documentStore.js из-за дублирования функции
- Ошибка "require is not defined" при попытке анализа текста из-за неправильного использования require в ES modules
- Ошибка "Unrecognized algorithm name" при использовании Web Crypto API, не поддерживающего MD5 в Node.js
- Проблемы с перезапуском сервера при изменениях в файле db.json
- Неполный анализ текста с возвратом "Failed to generate brief summary"

### Решение:
- Устранено дублирование функции `analyzeDocument` в documentStore.js
- Исправлено использование криптографических функций с переходом на правильный import в ES modules
- Настроено игнорирование файла db.json в nodemon для предотвращения нежелательных перезапусков сервера
- Улучшена обработка ошибок и логирование в AIService
- Оптимизированы параметры запросов к AI модели

### Изменения в файлах:

#### frontend/src/stores/documentStore.js
- **Удалено дублирование функции `analyzeDocument`**: Удалена одна из двух объявленных функций с одинаковым именем
- **Исправлены вызовы функций анализа**: Обновлены вызовы функций в компонентах DocumentReview.vue и DocumentsList.vue

#### frontend/src/views/DocumentReview.vue
- **Исправлен вызов analyzeDocument**: Убрано передача параметра documentId, так как функция теперь получает его из текущего документа

#### frontend/src/views/DocumentsList.vue
- **Удален неиспользуемый код**: Удалены переменные и функции, связанные с диалогом жалоб, которые больше не используются
- **Упрощена логика анализа**: Анализ документов теперь происходит напрямую без промежуточных диалогов

#### backend/package.json
- **Добавлено игнорирование db.json**: В конфигурацию nodemon добавлен файл db.json в список игнорируемых для предотвращения перезапусков сервера

#### backend/services/aiService.js
- **Исправлено использование криптографии**: Заменено использование require('crypto') на правильный import crypto from 'crypto'
- **Обновлена функция generateCacheKey**: Исправлена реализация с использованием crypto.createHash('md5') вместо Web Crypto API
- **Улучшено логирование**: Добавлены дополнительные сообщения для отладки процесса анализа
- **Оптимизированы параметры запросов**: Уточнены параметры temperature и другие настройки для улучшения качества анализа

#### backend/routes/documentRoutes.js
- **Удалены дублирующие функции**: Удалены функции analyzeDocumentContent, analyzeDocumentContentFromAttachment, analyzeAttachments

### Результаты:
1. **Устранены синтаксические ошибки**: Исправлены ошибки дублирования идентификаторов
2. **Исправлена работа с криптографией**: Корректное использование криптографических функций в ES modules
3. **Предотвращены нежелательные перезапуски**: Настроено игнорирование файла БД nodemon'ом
4. **Улучшена стабильность**: Сервер больше не перезапускается при сохранении документов
5. **Упрощена архитектура**: Удалены дублирующие функции и упрощены потоки данных
6. **Улучшено логирование**: Добавлены сообщения для отладки процесса анализа
