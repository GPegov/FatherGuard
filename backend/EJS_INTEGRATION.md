# Интеграция EJS шаблонизатора в complaintService.js

## Обзор

Этот документ описывает интеграцию EJS шаблонизатора в существующий сервис генерации жалоб (complaintService.js) проекта FatherGuard. Интеграция позволяет использовать HTML-шаблоны для создания формализованных жалоб в различных государственных органах.

## 1. Необходимые изменения в complaintService.js

### Добавленные зависимости:
1. Импорт EJS модуля
2. Импорт модулей для работы с файловой системой
3. Получение директории в ES модулях

### Добавленные методы:
1. `getTemplatePath(agency)` - определяет путь к шаблону в зависимости от типа органа
2. `prepareTemplateData(mainDocData, relatedDocsData, agency, complaintResult)` - подготавливает данные для шаблона
3. `renderComplaintTemplate(agency, templateData)` - рендерит шаблон с данными
4. `generateFallbackWithTemplate(documentData, relatedDocsData, agency)` - резервный механизм генерации

### Измененные методы:
1. `generateUnifiedComplaint()` - теперь генерирует как текстовую, так и шаблонизированную версию жалобы
2. `createComplaintObject()` - добавлено поле `templatedContent` для хранения HTML версии
3. `generateWithAI()` - добавлена обработка ошибок шаблонизации с резервным механизмом

## 3. Механизм выбора шаблона в зависимости от типа органа

Выбор шаблона осуществляется в методе `getTemplatePath(agency)`:

1. Если в названии органа содержится "фссп" (независимо от регистра), используется шаблон `fssp-complaint.ejs`
2. Для всех остальных органов используется универсальный шаблон `official-complaint.ejs`

Примеры:
- "Федеральная служба судебных приставов" → `fssp-complaint.ejs`
- "Управление социальной защиты" → `official-complaint.ejs`

## 4. Обработка ошибок при рендеринге шаблона

Обработка ошибок реализована на нескольких уровнях:

1. **Проверка существования файла шаблона**:
   ```javascript
   if (!fs.existsSync(templatePath)) {
     throw new Error(`Шаблон не найден: ${templatePath}`);
   }
   ```

2. **Оборачивание вызова рендеринга в try-catch**:
   ```javascript
   try {
     const renderedHtml = await ejs.renderFile(templatePath, { data: templateData });
     return renderedHtml;
   } catch (error) {
     console.error('Ошибка рендеринга шаблона:', error);
     throw error;
   }
   ```

3. **Резервный механизм генерации**:
   При ошибках генерации через AI или шаблон, система использует запасной текстовый вариант жалобы

## 5. Поддержка резервного механизма генерации при ошибках шаблонизации

Резервный механизм реализован через метод `generateFallbackWithTemplate()`:

1. При ошибках AI генерации система пытается сгенерировать жалобу через шаблон
2. При ошибках шаблонизации система возвращает текстовую версию жалобы
3. Все этапы логируются для последующего анализа

Пример использования резервного механизма:
```javascript
} catch (aiError) {
  console.error('Ошибка AI генерации:', aiError);
  // Генерируем запасной вариант через шаблон
  const templateData = this.prepareTemplateData(mainDocData, relatedDocsData, agency, {});
  try {
    const templatedComplaint = await this.renderComplaintTemplate(agency, templateData);
    return {
      content: this.generateFallbackComplaint(mainDocData, agency),
      templatedContent: templatedComplaint
    };
  } catch (templateError) {
    console.error('Ошибка генерации шаблона:', templateError);
    // Если шаблон не работает, возвращаем только запасной вариант
    return {
      content: this.generateFallbackComplaint(mainDocData, agency)
    };
  }
}
```
