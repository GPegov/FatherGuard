# Шаблоны жалоб для FatherGuard

Этот каталог содержит EJS-шаблоны для генерации официальных жалоб в различные государственные органы, включая Федеральную службу судебных приставов (ФССП).

## Структура файлов

1. `official-complaint.ejs` - Универсальный шаблон жалобы для различных государственных органов
2. `fssp-complaint.ejs` - Специализированный шаблон жалобы для ФССП
3. `complaint-data-example.json` - Пример структуры данных для генерации жалобы

## Использование шаблонов

Шаблоны используют EJS (Embedded JavaScript templating) для вставки данных и логики в документ.

### Основные элементы синтаксиса EJS:

1. `<%= переменная %>` - Вывод значения переменной
2. `<% if (условие) { %>...<% } %>` - Условная логика
3. `<% массив.forEach(function(item) { %>...<% }); %>` - Циклы для отображения списков

### Доступные переменные:

Все шаблоны ожидают объект `data` со следующими полями:

- `complaintDate` - Дата подачи жалобы
- `recipient` - Наименование получателя жалобы
- `recipientPosition` - Должность получателя (для ФССП)
- `recipientAddress` - Адрес получателя
- `fsspDepartment` - Отделение ФССП (для специализированного шаблона)
- `applicantFullName` - ФИО заявителя
- `applicantAddress` - Адрес заявителя
- `applicantPhone` - Телефон заявителя
- `applicantEmail` - Email заявителя
- `documentDate` - Дата документа, на который подается жалоба
- `documentNumber` - Номер документа
- `documentAgency` - Орган, выдавший документ
- `documentSummary` - Краткое содержание документа
- `executiveProductionNumber` - Номер исполнительного производства (для ФССП)
- `violations` - Массив нарушений
- `legalReferences` - Массив ссылок на нормативные акты
- `requirements` - Массив требований
- `attachments` - Массив приложений
- `complaintNumber` - Номер жалобы

## Генерация документов

Для генерации документов из шаблонов в коде проекта используется следующий подход:

```javascript
import ejs from 'ejs';
import fs from 'fs';

// Загрузка данных
const complaintData = JSON.parse(fs.readFileSync('complaint-data-example.json'));

// Рендеринг шаблона
ejs.renderFile('fssp-complaint.ejs', { data: complaintData }, (err, html) => {
  if (err) {
    console.error(err);
    return;
  }
  
  // Сохранение результата
  fs.writeFileSync('generated-complaint.html', html);
});
```

## Кастомизация

Шаблоны могут быть адаптированы для других государственных органов путем изменения:
1. Реквизитов получателя
2. Специфических ссылок на законодательство
3. Специфических требований
4. Формы обращения (должностному лицу, в организацию и т.д.)

## Особенности форматирования

Шаблоны включают:
- Стили для делового документооборота
- Правильные отступы и поля
- Поддержку многостраничных документов с разрывами страниц
- Раздел приложений с нумерацией
